# Edit Employee Dicipline Type

> **Module:** `ssi_hr_dicipline`\
> **Model:** `hr.dicipline_type`\
> **Menu:** Human Resource > Configuration > Career > Employee Dicipline Types\
> **Actor:** user in group `Human Resource - Configurator / Employee Dicipline Type`\
> **Requires:** `01-create`

## Pre-Condition

- None.

## Flow

1. Open the **Human Resource > Configuration > Career > Employee Dicipline Types** menu.
2. Find and open the record to edit.
3. Click the **Edit** button. **(14.0 only — the form opens directly editable on
   16.0+)**
4. Change the required fields.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
