# Delete Employee Dicipline Type

> **Module:** `ssi_hr_dicipline`\
> **Model:** `hr.dicipline_type`\
> **Menu:** Human Resource > Configuration > Career > Employee Dicipline Types\
> **Actor:** user in group `Human Resource - Configurator / Employee Dicipline Type`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record is not referenced by any Dicipline record.

## Flow

1. Open the **Human Resource > Configuration > Career > Employee Dicipline Types** menu.
2. Open the record to delete.
3. Click **Action** > **Delete**.
4. Click **OK** to confirm.
5. Click the **Employee Dicipline Types** breadcrumb to return to the list.

## Post-Condition

- The record is permanently removed from the system.
- The list view no longer shows the deleted record.
