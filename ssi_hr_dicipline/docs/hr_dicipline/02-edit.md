# Edit Dicipline

> **Module:** `ssi_hr_dicipline`\
> **Model:** `hr.dicipline`\
> **Menu:** Human Resource > Career Management > Employee Diciplines\
> **Actor:** user in group _Employee Dicipline / User_\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** Status is **Draft**.
- **Access:** User is in group _Employee Dicipline / User_.

## Flow

1. Open the **Human Resource > Career Management > Employee Diciplines** menu.
2. Find and open the record to edit.
3. Click the **Edit** button. **(14.0 only — the form opens directly editable on
   16.0+)**
4. Change the fields that need to change, for example **Date Dicipline**, **Type** or
   **Reason**.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
