# Create Employee Dicipline Reason

> **Module:** `ssi_hr_dicipline`\
> **Model:** `hr.dicipline_reason`\
> **Menu:** Human Resource > Configuration > Career > Employee Dicipline Reasons\
> **Actor:** user in group `Human Resource - Configurator / Employee Dicipline Reason`

## Pre-Condition

- None.

## Flow

1. Open the **Human Resource > Configuration > Career > Employee Dicipline Reasons**
   menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the required fields:
   - **Name**: Enter the name.
   - **Code**: Enter a unique code, or fill with **/** to generate it later using the
     **Generate Code** button.
4. Click **Save**.

## Post-Condition

- A new Employee Dicipline Reason record is created and available for selection on a
  Dicipline record.
