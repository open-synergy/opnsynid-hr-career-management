# Delete Employee Dicipline Reason

> **Module:** `ssi_hr_dicipline`\
> **Model:** `hr.dicipline_reason`\
> **Menu:** Human Resource > Configuration > Career > Employee Dicipline Reasons\
> **Actor:** user in group `Human Resource - Configurator / Employee Dicipline Reason`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record is not referenced by any Dicipline record.

## Flow

1. Open the **Human Resource > Configuration > Career > Employee Dicipline Reasons**
   menu.
2. Open the record to delete.
3. Click **Action** > **Delete**.
4. Click **OK** to confirm.
5. Click the **Employee Dicipline Reasons** breadcrumb to return to the list.

## Post-Condition

- The record is permanently removed from the system.
- The list view no longer shows the deleted record.
