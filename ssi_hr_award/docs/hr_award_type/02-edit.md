# Edit Award Type

> **Module:** `ssi_hr_award`\
> **Model:** `hr.award_type`\
> **Menu:** Human Resource > Configuration > Career > Employee Award Types\
> **Actor:** user in group _Employee Type Reason_\
> **Requires:** `01-create`

## Pre-Condition

- **Access:** User is in group _Employee Type Reason_.

## Flow

1. Open the **Human Resource > Configuration > Career > Employee Award Types** menu.
2. Find and open the record to edit.
3. Click the **Edit** button. **(14.0 only — the form opens directly editable on
   16.0+)**
4. Change **Employee Award Reason** or **Code** as needed.
5. Click **Save**.

## Post-Condition

- The record is updated with the new values.
